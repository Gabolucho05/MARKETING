# MARKETING

## Skills de Instagram (instaladas desde sergebulaev/instagram-skills, licencia MIT)

Ubicadas en `.claude/skills/` — Claude Code las carga automáticamente al abrir este repo.

| Skill | Para qué sirve |
|---|---|
| `instagram-marketing` | Índice/enrutador: decide cuál skill de IG usar |
| `ig-caption-writer` | Copy con gancho en los primeros 125 caracteres + CTA |
| `ig-carousel-planner` | Carrusel slide por slide (hasta 10) |
| `ig-hook-extractor` | Desarma el gancho de un Reel/carrusel viral |
| `ig-hashtag-strategist` | Set de 3–5 hashtags por tamaño (nicho/medio/amplio) |
| `ig-humanizer` | Quita "tics de IA" del copy; `--mode audit` revisa antes de publicar |
| `ig-content-planner` | Plan semanal de Reels, carruseles e historias |
| `ig-repurposer` | Convierte LinkedIn/blog/YouTube/X en post nativo de IG |
| `ig-profile-optimizer` | Auditoría de perfil: bio, nombre, highlights, grid |
| `ig-audience-insights` | Lectura de nicho/competencia (Apify opcional; si no, pegas los datos) |

Referencias compartidas en `.claude/references/`. Publicar vía Publora, Apify y Pixfaro son **opcionales** (requieren sus propias API keys); sin ellas las skills redactan y tú publicas manualmente. Licencia original: `.claude/references/INSTAGRAM-SKILLS-LICENSE`.
