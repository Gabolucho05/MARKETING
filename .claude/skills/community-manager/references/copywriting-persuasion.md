# Copywriting y Persuasión

Todo copy orgánico se construye desde un objetivo de comportamiento declarado, con un framework de persuasión deliberado — nunca "se me ocurrió así".

## 1. Definir el objetivo de comportamiento primero

Antes de escribir una sola palabra, decidir qué acción específica se busca:

| Objetivo | Qué cambia en el copy |
|---|---|
| Que comente | Pregunta abierta, invitación a opinar, algo polémico-ligero o relatable |
| Que guarde (save) | Contenido de valor/utilidad ("guarda esto para después"), listas, tips |
| Que comparta | Contenido identificable ("etiqueta a quien necesita ver esto"), humor, sorpresa |
| Que escriba por WhatsApp | Oferta clara + urgencia real + CTA directo con link armado |
| Que reconozca la marca (awareness) | Consistencia de voz repetida, sin pedir acción transaccional |

Un copy que persigue dos objetivos a la vez ("comenta y también cómprame ya") generalmente no logra ninguno bien — igual principio de mensaje único que usa `estrategia-planificacion` para campañas completas, aplicado a nivel de un solo post.

## 2. Frameworks de persuasión

### AIDA (Atención, Interés, Deseo, Acción)
Bueno para posts de venta directa o lanzamiento:
- **Atención**: hook que detiene el scroll (primera línea, sin desperdiciar caracteres en contexto innecesario).
- **Interés**: por qué le importa a esta persona específica, no genérico.
- **Deseo**: qué cambia en su vida/negocio si actúa.
- **Acción**: CTA explícito, sin ambigüedad.

### PAS (Problema, Agitación, Solución)
Bueno para contenido de dolor/necesidad, o para posts educativos que derivan en venta:
- **Problema**: nombrar la frustración específica, no genérica.
- **Agitación**: profundizar por qué ese problema duele/cuesta si no se resuelve.
- **Solución**: presentar el producto/servicio como la salida natural, no forzada.

### Antes/Después/Puente
Bueno para transformación (resultado de cliente, testimonio, caso de uso):
- Antes (situación sin el producto) → Después (situación con el producto) → Puente (cómo se llega, que es contratar/comprar).

### Storytelling de marca
Bueno para contenido de awareness/conexión, no venta directa:
- Una situación real y específica (propia o de un cliente), con un momento de tensión y una resolución que conecta con el valor de marca — sin forzar un CTA de venta al final si el objetivo es solo conexión.

**Regla:** elegir UN framework por pieza, no mezclar los cuatro en un mismo copy. Declarar cuál se usó (en la respuesta al usuario, no en el copy publicado) para que quede claro el porqué de la estructura.

## 3. CTA por plataforma (contexto Venezuela)

| Plataforma | CTA típico |
|---|---|
| Instagram/TikTok (post/reel) | "Escríbenos por WhatsApp" con el link `wa.me` ya armado (ver `utm-y-whatsapp.md` de `analitica-metricas` si la campaña necesita medirse) |
| Stories | Sticker de pregunta/encuesta si el objetivo es interacción; link directo si el objetivo es cierre |
| Comentarios propios (para fijar) | Reforzar el CTA principal sin repetir el copy completo |

El CTA de WhatsApp siempre lleva el link completo y funcional, no "escríbenos" a secas sin el enlace — quitar fricción es parte del trabajo de copy, no un detalle técnico aparte.

## 4. Estructura de entrega

Cuando se pide un copy, entregar:
1. El copy final, listo para publicar (sin asteriscos de énfasis, con emojis solo si aportan, no decorativos).
2. Una línea declarando el framework usado y el objetivo de comportamiento (para el usuario, no para publicar).
3. El CTA con el link ya armado si aplica.
4. Si la pieza es parte de una campaña de `paid-media`, referenciar el ángulo de venta que ilustra, para mantener consistencia de mensaje entre lo orgánico y lo pauteado.

## 5. Errores comunes a evitar

- Copy con dos CTAs distintos compitiendo (ej. "comenta" y "escríbenos" en el mismo post).
- Hook genérico ("no te puedes perder esto") sin especificidad real.
- Framework de venta dura (AIDA) en contenido cuyo objetivo real era solo awareness — desalinea el copy con el objetivo declarado.
- CTA de WhatsApp sin el link armado, dejándole la fricción de buscar el contacto al usuario.
